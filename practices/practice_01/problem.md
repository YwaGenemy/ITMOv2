# Проблема и метрики

## Проблема

- Пользователь: разработчик, выполняющий code review.
- Ситуация: нужно оценить небольшой PR и получить проверяемый список рисков.
- Сейчас: общий запрос к LLM дал замечания без точных доказательств, а улучшенный запрос - рекомендации вместо проверок; см. [сравнение запусков](prompts.md#сравнение-двух-запусков).
- Последствие: ревьюер тратит время на перепроверку и может принять неподтверждённый совет.
- Вне задачи: автоматические исправления, approve/merge, публикация комментариев, анализ всего репозитория и разработка production-сервиса в рамках этой домашки.

## Метрики

Числа ниже - цели пилота, а не измеренные результаты. Baseline пока не собран.

| Метрика | Текущее значение или способ замера | Целевое изменение | Когда измеряем | Источник данных |
|---|---|---|---|---|
| Медиана времени до проверенного списка замечаний | Неизвестна; один набор из 20 синтетических diff, сопоставимые группы, порядок условий чередуется | Сократить на 20% относительно ручного ревью без падения точности | После прототипа | Время начала/окончания в отдельном журнале эксперимента |
| Доля подтверждённых рисков | Число принятых экспертом / число всех выданных рисков; при нуле рисков - N/A | >= 90% на наборе из 20 diff с заранее заданными дефектами | После обоих режимов ревью | Независимая разметка с доказательствами |
| Полнота на известных дефектах | Найденные эталонные дефекты / все эталонные дефекты; не более трёх целевых дефектов на diff | Не ниже ручного baseline | Вместе с точностью | Тот же набор и эталон |
| Выполнение обязательных контрактов | Доля успешных проверок SEC/API/REL/OUT/OBS | 100% предусмотренных синтетических случаев | Перед пилотом | Будущие тестовые отчёты; сейчас только [планы](tests_integration.md) |

## Почему изменение метрики подтвердит решение проблемы

Снижение времени при сохранении точности и полноты означает, что помощник уменьшает работу ревьюера. Одна точность недостаточна: пустой список рисков не должен выглядеть улучшением. Экспертная разметка ещё не выполнена; эффект не заявляется доказанным.
