## Запрос

````prompt
Русский язык, до 350 слов. Верни только итоговый ответ без скрытых рассуждений. Не используй инструменты, web, shell и не меняй файлы. Это план тестов будущего сервиса; не утверждай, что они выполнены. Нормативный источник — CASE, статусы кроме 413 — проектные решения Context Pack.

Техника Chain of Verification. Проверь предложения для integration-плана, возникшие после ответа P1-02: «длинный diff нужно обрезать», «автоэкранирование гарантирует отсутствие prompt injection», «если в diff нет try/except, в приложении точно нет логирования», «все ошибки LLM возвращаем HTTP 500».
Сначала составь 4 явных вопроса проверки; затем ответь по CASE/Context Pack, помечая неизвестное и проектные решения; в конце дай исправленный абзац для tests_integration.md. Сохраняй только вопросы, evidence и исправления.

````

Полный запрос со снимками источников: [request.md](evidence/request.md).

| Вопрос | Ответ | Основание |
|---|---|---|
| Обрезать длинный diff? | Нет, вернуть 413 | CASE, API-1 |

| Нет try/except значит нет логирования? | Нет, остальной код неизвестен | Diff не показывает middleware и адаптер |
