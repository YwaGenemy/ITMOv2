## Как воспроизвести

Из корня репозитория открыть новую сессию OpenCode на указанной модели в Plan. Отправить полный текст соответствующего `evidence/request.md`; для первых пяти все выбранные источники уже включены как снимки. Не добавлять контекст из других экспериментов. Для ReAct нужны два разрешённых чтения, снимки исходных файлов лежат в его evidence. Текущий tests_integration.md содержит исправления после эксперимента, поэтому повторный запуск на текущем файле может дать другой результат.

CLI-форма: `opencode run --pure --agent plan --model opencode/nemotron-3-ultra-free --format json "<полный текст request.md>"`. `--auto` не используется. План запрещает правки, но соблюдение остальных границ нужно проверять по журналу действий.

Первым пяти запросам передан один и тот же базовый план; изменения внесены последовательно и сохранены в отдельных `changes.diff`. ReAct проверяет уже дополненный план. После экспериментов тексты сокращены; `changes.diff` сохраняет изменения на момент эксперимента. Повторный запуск может дать другой ответ.
