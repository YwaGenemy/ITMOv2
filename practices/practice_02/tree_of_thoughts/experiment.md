# Tree of Thoughts

Решение: выбрать тестовый стенд для границы API→адаптер→LLM. Критерии: воспроизводимость, транспорт, независимость от квот.

- Инструмент / модель: OpenCode CLI 1.18.31, `opencode/nemotron-3-ultra-free`, agent plan.
- Session: `ses_f39ede233ffeIM1DehnPsFWt0H`. Реальный запуск, код завершения 0.
- Исходный артефакт: [tests_integration.md](../../practice_01/tests_integration.md); его состояние на момент запроса включено в [request.md](evidence/request.md).

## Запрос

````prompt
Русский язык, до 350 слов. Верни только итоговый ответ без скрытых рассуждений. Не используй инструменты, web, shell и не меняй файлы. Это план тестов будущего сервиса; не утверждай, что они выполнены. Нормативный источник — CASE, статусы кроме 413 — проектные решения Context Pack.

Техника Tree of Thoughts. Выбери способ проверять API→адаптер→LLM в integration-плане. Публично опиши три альтернативы: A fake Python-объект вместо адаптера, B локальный fake HTTP-провайдер через настоящий адаптер, C настоящий внешний LLM.
Критерии: воспроизводимость timeout/error, покрытие транспортного контракта, независимость от квот и отсутствие передачи реальных секретов. Верни таблицу плюсов/минусов/оценки по каждому критерию, выбор и проверку выбора. Только внешние альтернативы и итог, без скрытого хода рассуждений.

````

Полный запрос со снимками источников: [request.md](evidence/request.md).

## Что получили

| Вариант | Плюсы | Минусы |
|---|---|---|
| A: fake Python-объект | Простой, детерминированный | Не проверяет HTTP-адаптер |
| B: локальный fake HTTP-провайдер | Проверяет транспорт и позволяет задавать ошибки | Нужно настроить локальный сервер |
| C: внешний LLM | Проверяет реального провайдера | Зависит от квот, сети и ответа модели |

Модель выбрала B. Её численные оценки пересчитаны ниже.

Полный ответ: [response.md](evidence/response.md). Журнал запуска: [run.json](evidence/run.json).

## Проверка альтернатив и выбора

Оценки субъективны и предложены моделью. Пересчёт по её весам 0.4/0.35/0.25: A = 3.95, B = 4.60, C = 2.05. В ответе неверны все три суммы; победитель B сохраняется. Изоляция сама по себе не доказывает OBS-1.

В журнале выполнения зафиксирована одна попытка `write` в integration_approach_analysis.md вопреки запрету запроса. Режим plan её заблокировал; файл не создан. Попытка отмечена как нарушение условий эксперимента.
