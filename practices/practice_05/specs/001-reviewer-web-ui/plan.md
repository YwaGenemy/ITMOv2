# Implementation Plan: Веб-страница ревьюера

**Branch (идентификатор setup-plan)**: `001-reviewer-web-ui` | **Date**: 2026-10-27 | **Spec**: [spec.md](spec.md)

**Фактическая Git-ветка**: `practice_05`; каталог фичи независим от ветки.
**Input**: `specs/001-reviewer-web-ui/spec.md`, общий `specs/contract.md` и ограничение человека: один HTML-файл со встроенным JS, без сборки и фреймворков. Сервер и `GET /` готовы в фиче 002.

## Summary

Заменить заглушку `app/static/index.html` одним русскоязычным экраном: ввод diff, одна отправка в `POST /api/reviews`, сводка, 0–3 риска и проверки. Чистые HTML/CSS/JS, нативные DOM и Fetch API. Проверять всю схему успеха до отображения, соблюдать точные ошибки общего контракта и общий клиентский срок 15 секунд. Сохранять ввод, блокировать форму на время запроса и исключать влияние поздних ответов.

## Technical Context

**Language/Version**: HTML5, CSS, стандартный JavaScript современных браузеров; существующий Python 3.10+ (синтаксис `dict | None`) для сервера и проверок.
**Primary Dependencies**: DOM, Fetch, AbortController, performance.now, таймеры; сервер — стандартная библиотека Python. Новых пакетов, CDN, сборщика и браузерного тестового фреймворка нет.
**Storage**: Только память страницы и поле ввода; без localStorage, истории и восстановления после перезагрузки.
**Testing**: Единственная команда `sh scripts/check.sh` (compileall + pytest). По уточнению человека pytest запускает Node.js `node:test` без браузера и npm-пакетов: исполняется JS из HTML для проверки разбора ответа, выбора ошибок, формы и сроков. Дополнительная браузерная приёмка — по `quickstart.md`. Существующие API-тесты используют `handle_review` и `FakeLLM`.
**Target Platform**: Современный браузер с указанными Web API, страница и API одного origin; локальный сервер `python -m app.server`.
**Project Type**: Одностраничный интерфейс существующего HTTP-сервиса.
**Performance Goals**: Одна активная проверка; не более 15 секунд до принятия результата, включая тело и обработку; запуск за два действия (вставка и отправка). Серверный срок LLM — 10 секунд.
**Constraints**: Один файл `app/static/index.html`, встроенные CSS/JS; точный ввод без trim при отправке и без проверки длины; 0–3 риска; только текстовый DOM; клавиатура и screen reader; никаких автоматических повторов и логирования содержимого.
**Scale/Scope**: Один экран, пять групп состояний, четыре специальные пары HTTP/кода; сервер принимает до 20 000 Unicode code points. Работа команды UI ограничена содержимым страницы и проверкой поведения.

## Phase 1 — Design & Contracts

- [quickstart.md](quickstart.md): запуск готового сервера и детерминированные сценарии RED/GREEN без реальной модели.

Порядок последующей реализации: зафиксировать падение сценария на заглушке, добавить форму и состояния; затем покрыть ответы, безопасный вывод и дедлайн контролируемыми сценариями перед соответствующим кодом. После GREEN выполнить единую проверку. Подробные задачи относятся к `/speckit.tasks`.
